# Self-hosted fonts

The application uses these Latin variable WOFF2 files:

- `Inter-Variable.woff2`
- `SpaceGrotesk-Variable.woff2`

They are distributed by the `@fontsource-variable/inter` and
`@fontsource-variable/space-grotesk` 5.3.0 packages under the SIL Open Font License.
The corresponding license files are retained in this directory.
